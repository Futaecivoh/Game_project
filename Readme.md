# Игра в жанре Cardgame

Простая CardGame игра разработываемая в рамках 3 курса "ООП и Гибкая методология разработки" в МПГУ ИМО

## Концепция

Консольная пошаговая RPG-игра с элементами карточной системы. Игрок управляет персонажем "Кирильченко", путешествующим по игровой карте через различные локации, сражаясь с врагами и боссами.

**Основные механики:**
- **Система здоровья**: HP отображается в виде визуальной полосы с числовым отображением
- **Система уровней**: Набор опыта повышает уровень персонажа
- **Система оружия**: Экипировка различных видов оружия с разными характеристиками урона
- **Враги и боссы**: Разнообразные враги с различным поведением (агрессивное, пассивное, бегство)
- **Сохранение игры**: Система сохранений для продолжения прогресса

## Запуск

1. **Требования**: .NET 9.0 и выше
2. **Компиляция**: 
   ```
   dotnet build
   ```
3. **Запуск игры**:
   ```
   dotnet run --project MyGame.Console
   ```
4. **Запуск тестов**:
   ```
   dotnet test "NUnit Tests"
   ```

## Управление

*Команды вводятся в консоль:*
- **Движение**: Команды для перемещения между локациями
- **Атака**: Атака врагов с использованием экипированного оружия
- **Карты**: Использование карт боевой системы
- **Сохранение/Загрузка**: Сохранение и загрузка прогресса игры
- **Пауза**: Приостановка игры
- **Выход**: Выход из игры

## Структура проекта

- **Core/**: Основные системы (GameManager, WorldMap, Location, SaveService)
- **Entities/**: Классы персонажей (Player, Enemy, Boss, Creature)
- **Items/**: Система оружия и карт
- **Commands/**: Паттерн Command для управления действиями
- **FSM/**: Конечный автомат состояний игры
- **Factory/**: Фабрики для создания персонажей
- **Builder/**: Построители для создания карты и боссов
- **Behaviours/**: Система поведения врагов
